# 语义归一化实施包

本包配合《历史论点语义归一化与收敛度实证方案》使用。它提供可复算的统计核心与编码模板，不把未标注的原文自动当作经过验证的语义类别。

## 文件

- `aci_reference.py`：Python 3.9以上可运行，仅用标准库。输入已经核验的concept_id，输出ACI′_J、U/T、端点修正版、距离矩阵、出现率；在独立固定归一化条件下输出删除整轮的jackknife标准误、Hoeffding保守区间、独立两组整轮置换。
- `test_aci_reference.py`：指标与输入校验测试。
- `example_input.json`和`example_result.json`：纯构造示例，三轮集合分别为{a,b,c}、{a,b,d}、{a,b,c}，预期ACI′_J=1/3，U/T=4/9。不是茶叶经济实验结果。
- `normalization_prompts.json`：保真原子化与六类语义关系判定模板，需要开发验证后冻结。
- `annotation_record_template.json`：双人独立标注和裁决记录字段示例。
- `runs_audit.json`与`runs_pairs.txt`：对当前three runs材料的结构核查及原始案例，仅作为开发依据。没有完成正式等义归并。

## 运行

进入本文件夹，在终端执行：

```sh
python3 aci_reference.py example_input.json --output example_result.json
python3 -m unittest -v test_aci_reference.py
```

程序不会访问网络，不会调用LLM，也不会收费。实际实验先由外部流程产生经核验的类别ID，再按example_input结构提供每轮出现的ID。不能把原句直接当concept_id，不能每轮各自重新编号。所有条件共享同一类别体系；同一轮内部重复ID自动去重。

## 统计条件

`fixed_normalization=true`是研究者对“规则或映射独立于当前分析运行而固定”的明确声明。对全部当前输出联合创建类别、再保存下来，不足以满足该条件。尚未满足时填false，程序仅给描述性结果。这比只冻结当前映射后照常推断更保守。

程序提供jackknife标准误，但不计算方案中的t近似区间，以避免小样本中机械输出貌似精确的区间。正式n足够、非退化且假设满足时，可由统计分析程序另行按方案计算t临界值区间。Hoeffding界通常很宽，其假设不能由软件自动验证；它不包括语义归一化误差。

两组输入使用`groups: {"A": [运行记录], "B": [运行记录]}`替代`runs`。仅适用于单案例、独立两组、固定映射；默认9999次置换，种子1729。零假设是完整输出分布相同或标签可交换，强于ACI期望相同。分层、配对、多论文或批次设计须扩展程序，不能直接混合运行。

成功记录用status=ok，失败用failed，缺失用missing。失败和缺失单列并排除，分数条件于非空成功输出。合法空输出会阻止主分析；只有已经预先规定并有理由时使用`--exclude-empty-ok`，明确报告改变后的研究对象。不要删除失败记录后隐瞒失败率。

## 第一遍预实验

1. 核对原始输入、实际提示词版本和运行元数据，建立跨轮唯一ID。
2. 历史学两人先核验20—30个母节点的原子化，修订编码手册，保存限定与来源。
3. 在开发集双人独立标注150—200对，并在小块建立60—100条命题的参考分簇。上述数量仅为启动建议。
4. 召回候选，执行六类判断，检查簇内成员两两等义以及非传递冲突。人工核验未召回等义对。
5. 在冻结测试集报告讨论前一致性、合并P/R/F1和B³；不拿挑战集代替自然分布评价。
6. 将经裁决类别转换为每轮0/1集合，计算ACI。保持原子命题不变，重复归一化和顺序扰动，单独报告测量敏感性。
7. 根据预实验决定正式n、案例数和停止规则。3轮不能支持正式稳定性结论。
