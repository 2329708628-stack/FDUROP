## 1. 实验设置

| 项 | 内容 |
|---|---|
| 论文 | A05（开封动物交易市场）、B05（宋代市镇社会群体）、C01（范成大出世入世） |
| 条件 | Q = 给定研究问题、自下而上分析；A = 给定顶层观点（A_H）、以论带史 |
| 档位 | A05：S（核心句）/ M（±100 字）/ L（±200 字）；B05、C01：全量档 AUTO |
| 生成模型 | deepseek-chat，temperature=0.7，max_tokens=32768，单轮生成 |
| 人类基准 | A05 30 条 C / B05 50 条 C / C01 17 条 C（v3.2 机械抽取管线产出） |
| 判定模型 | deepseek-chat，temperature=0，逐对判定，严格 JSON 输出 |

**判定管线**（`脚本/步骤8_Q_A_实验/_llm_judge.py`）：

```
mDeBERTa 句向量 → 双向 top-5 召回候选对（人→模、模→人 取并集）
→ LLM 三档判定（等义 / 部分重叠 / 不等义）
→ 双向聚合：
   人类侧覆盖 = 有任一命中边的人类主张数 / 人类主张总数   ← 主指标
   模型侧 precision = 有任一命中边的模型主张数 / 模型主张总数  ← 独立维度
```

三档判据原文：

> - 等义：两条表达相同的命题/主张，允许措辞不同。
> - 部分重叠：一条命题是另一条的子命题，或两条共享部分论点但各有侧重。
> - 不等义：两条命题不同，仅主题相近或完全无关。

## 4. 问题清单（现象 → 依据 → 影响 → 状态）

### P1 提示词变量不统一（已修复）

**现象**：Q/A 两组提示词除任务行外还有额外差异，实验的单变量设计被破坏。

**依据**（A05 存档 prompt 逐行 diff，`输入_prompt.txt` 317 行中差异全部集中在前 11 行）：

| 位置 | Q 组原文 | A 组原文 |
|---|---|---|
| 任务行 | `…请基于以下史料池，分析{问题}。` | `…请论证以下核心观点：【观点】{A_H}`（自变量本身） |
| 要求 1 | `严格依据所给史料展开论证…` | `严格依据所给史料池论证上述观点…`**`论证要以史料为支撑，史论结合。`** |
| 要求 2 | `（共三大部分，如下）` | `（共三大部分，主题围绕论证该观点自行拟定）` |
| 要求 2 附行 | `一级标题共三大部分，主题围绕研究问题自行拟定…标题须贴合史料实际内容` | **整行缺失** |
| 要求 3 | `…与论点直接相关` | `…与论证观点直接相关` |

另：A05 的 Q 侧当时用旧「强制三级标题」模板，A 侧用自适应模板——两侧连结构约束都不同。

**影响**：（a）Q/A 方向不可解释——A 侧多背了「史论结合」「围绕观点自拟标题」等额外要求，A05-M 的 A 侧主张数达 53 条（Q 侧 23 条）比即疑似由此诱导；（b）已实测到方向翻转三次（A05 S/M：Q>A；A05 L：A>Q；B05：A>Q），提示词统一前任何方向结论无效。

**状态**：已修复。建立共享模板 `脚本/步骤8_Q_A_实验/提示词模板.py`（正文唯一副本），两个生成脚本只提供任务行。验收 diff：改后 Q vs A 全文差异行数 = **3**（任务行 1→2 行），正文逐字相同；同时修复了 Q 侧 `？。` 尾标点与 `-    -` 双横线渲染瑕疵。

**待办**：A05 六组 + B05/C01 的 A 侧（共 8 个条件）需用统一提示词重跑。

### P2 判据「部分重叠」过宽，泛化型主张扫射式命中（待修复）

**现象**：C01/A_run_1 得 1.0/1.0（17/17 覆盖、21/21 precision）；进一步抽查发现 **A05/Q_run_1_S（本轮唯一的 Q 优势格之一）同样依赖扫射式命中**——P2 不止影响窄主题论文，它是全局性的。

**依据**（三组抽查）：

- C01/A：模型主张 21 条**全部**命中、人类 17 条**全部**命中（56 边）；极端例 `M[C2.1.2]`（"治理成都施利惠农、选将治兵"）**一条对 9 条人类主张**判「部分重叠」，含仅共享"儒臣尽责"主题的 `H[C1.10]`（"出使金国全节而归"）。
- A05/Q_run_1_S：`M[C3.2.2.1]`（"赁马赁驴租赁"）**一条对 15 条人类主张**，其中真正「等义」仅 `H[C5.7]`（租赁业）一条，其余 14 条为「部分重叠」——生猪龙头、马匹价格、牙人纠纷、屠宰业、水陆运输……只共享"开封动物市场活跃"这一**主题**；`M[C3.2.1.1]`（"市场规模巨大"）一条对 12 条。该 run 每条命中模型平均牵出 4.75 条人类主张（10 个 run 中最高）。
- 双向统计：命中图"每条命中模型 → 人类主张数"为 Q_S=4.75、A_M=1.67、A05 其余 2.3–2.8、C01 2.2–2.7——扫射强度按 run 波动，**不分条件**。

**病因**（修正早前版本）：不是"人类侧原子 vs 模型侧复合"——两侧同为 v3.2 盲态抽取产物，长度与分句数同构（A05 人类 49.2 字 / 2.20 分句；模型侧 40–68 字 / 1.0–3.2 分句，波动按 run 而非按侧）。真正机制是：**泛化型主张（概括句、总起句）+ 过宽的「部分重叠」定义（"共享部分论点"即可）= 扫射**——概括句天然"部分重叠"于一片具体主张。与旧余弦"主题相似淹没命题差异"同源，只是发生在判据定义层面。

**影响**：绝对水平普遍虚高且程度不均匀（按 run 波动）；**A05-S 的 0.80 与 C01/A 的 1.0 均不可用**，A05-M 亦受波及（每条被覆盖人类牵出 3.0 条模型主张）。收紧判据前，方向性结论一律不可下。

**修复方案**（待执行）：
1. 「部分重叠」收窄为：**核心命题必须相同，仅范围/限定不同**；
2. 仅共享主题或个别论据 → 归「不等义」；
3. 判定输出加 `shared_core` 字段（强制写出共同核心命题），写不出即不构成命中。

**验证方案**：先只用 C01/A + A05 冒烟反例重判（约 4 万 token），预期 C01/A 从 1.0 回落到 0.6–0.8 区间；通过后再全量重判。

### P3 绝对命中数的体积偏置（已用同预算检验抵消，报告口径需固化）

**现象**：模型侧 precision 的**分子**（命中模型主张数）每一档 A 都大于 Q：Q 12/16/21 vs A 15/27/25。

**依据**：
- 该分子随产出规模增长——A 在 A05 三档写出 27/53/32 条主张，是 Q（17/23/27）的 1.6–2.3 倍；
- 同预算模拟（§3.1）显示：抽稀到同等条数后，A05 的 A 侧覆盖从 17→13.1（S）、15→11.1（M）大幅回落，而 Q 不变；
- 冗余度（§3.2）：A_M 平均每条被覆盖人类主张牵出 3.00 条模型主张（Q_M 为 2.41），单点最多 8 条模型主张压在同一个人类主张上——是同一论点的反复重述，而非覆盖了新论点。

**影响**：绝对命中数跨条件不可比（"投篮命中次数"问题）。结论段禁止引用绝对值；报告必须用率（除以各自的 n）并附同预算检验。

**状态**：判定与检验已完成；**报告口径待固化**（建议把「同预算覆盖 + 冗余度」固化为判定脚本的输出字段，随重判一起产出）。

### P4 C 编号跨父撞号，静默丢节点（已修复）

**现象**：结语主张与第一章主张编号相撞（都叫 `C1.x`），按 id 建字典时静默覆盖，节点丢失。

**依据**：

| 文件 | 重复 id | 载入后节点数 |
|---|---|---|
| B05/A_human_baseline | `C1.1`（P5 与 P62 两条不同主张） | 50 → 49 |
| B05/A_run_1 | `C1.1`、`C1.2` | 34 → 32 |
| C01/A_run_1 | `C1.1` | 21 → 20 |

**根因**：`公共库.py::c_id_for` 对挂 A1 下的结语主张一律编 `C1.n`，其 docstring 写明假设——"A1->C1.n（**扁平篇**）"；论文带「一、二、三…」章节时必然与第一章撞号。校验器只查"每个父节点内编号连续"，不查全局唯一性，所以漏网；判定脚本按 id 建字典，所以静默丢节点。

**修复**：
- 数据：三个文件重编（结语主张续末章之后：B05 基准→C4.x、B05/A→C6.x、C01/A→C5.x），原件备份为 `run.json.bak_cidfix`；
- 生成器：`公共库.c_id_for` 增加 `chapter_count` 参数 + 三个调用点（`v3.2自动抽取.py`、`手工ABC_人类基准.py`、`run组装器.py`）+ 抽取提示词编号规则同步；
- 校验器：新增 **id 全局唯一性检查**；
- 判定脚本：`load_claims` 遇重复 id 直接报错退出。

**验证**：B05×3、C01/A、A05×2 回归校验全部 `ERRORS: NONE`。

### P5 C01/Q 抽取误指派（未修复）

**现象**：C01/Q_run_1 的 5 条结语主张（P33–P37）被抽取模型挂到 **B1** 名下（应挂 A1），同时第一章 P3 段（含 10 条 material_refs）**没有产出任何主张**。校验器报 5 个 ERROR（`anchor 不在父节点 span 内`）。

**依据**：`run校验器.py` 输出 5 ERROR；B1 的 span 为 `['P3','P4']` 而 5 条主张锚在 P33–P37；对照 C01/A_run_1 的同类主张正确挂在 A1 下。

**影响**：C01/Q 的主张集缺第一章内容 → 其覆盖率 0.7647 是**下界**；结构类指标（锚点 Jaccard 等）不可用。
（对判定本身影响有限：三档判定只比对主张文本，误挂的父节点不直接进入文本匹配。）

**延伸**：人类基准（A05 30 / B05 50 / C01 17 条）与模型侧是**同一条 v3.2 盲态抽取管线**的产物——分母自身也带抽取方差，并非人工书写的 ground truth（本轮 B05 基准即出现 P4 的重复 id 缺陷）。正式实验前建议对人类基准做一次双跑稳定性检查（两次抽取的 C 集合重合度）。

**修复**：重跑该篇抽取（`v3.2自动抽取.py`，数分钟 API 成本），或随干净轮全量重做。

### P6 A_H 注入偏差（历史遗留，未决）

**现象**：A 条件的自变量（给定顶层观点）本身可能未生效：`cos(A_H, humanA1) = 0.4785`，远低于 ≥0.65 的对齐目标（A_H 原文："开封动物交易市场繁荣反映宋代经济文化发达、政府管理成熟和市民文化繁荣"）。

**影响**：若给定观点与人类原文结论不对齐，A 条件的"以论带史"操纵就不是在测"围绕人类结论论证"，而是"围绕另一个相近观点论证"——直接影响 A 侧覆盖率的可解释性。

**状态**：未决。任何收敛度测量之前需先修：重写 A_H 对齐 humanA1，或改用 humanA1 原句作为操纵基准。
