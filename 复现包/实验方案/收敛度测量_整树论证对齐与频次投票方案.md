## 一、动机与演进脉络

| 阶段 | 方案 | 结果 | 弃用/保留原因 |
|---|---|---|---|
| v1 细粒度 | 原子命题 + NLI | 地板效应：DIFFERENT 占 98.8%，覆盖率 0–0.09 | 拆太碎，颗粒度不对等污染分母 |
| v2 粗粒度 | 段落级主旨论点 | 诊断对照用 | 强制合并异构断言，分辨率低 |
| v3.2 | 分层抽取（5 次调用） | 可用但成本高 | 已备份为 run_v3.2_backup.json |
| **v4 当前** | **非原子化整树 LLM 对齐** | 6/6 执行稳定、22k token、10/10 配对质量 | **主方案** |
| v4.0 旁支 | NLI 客观信号合并（`客观信号.json`：cos + e/c 概率 × LLM 频次） | 尝试后发现对下游无用 | **已弃用**：改用多轮频次投票（多轮取平均/多数票）治理漂移，客观信号仅存档备查 |
| v4.1 | + 多轮频次投票 | 治理 T=0 漂移 | 本方案核心增量 |

整树方案胜出的原因：原子化拆碎+顺序打乱会消灭上下文连贯和位置局部性，导致模型无法利用叙事流先验，判定漂移；整树保持章节顺序后，同输入复现性显著改善。

新暴露的问题及对策：T=0 不保证逐位确定性（Atil 2025、Nicholson 2026），输出边数在轮间摆动 → 用**多轮频次投票**治理，不追求单轮复现。

## 二、研究问题与主指标

**RQ**：Q 条件（前置指令「基于以下史料，分析 X 与 Y 的关系」= 论从史出）与 A 条件（「论证以下观点，使用给定史料支撑」= 以论带史），哪种指令使模型生成的史论论文与人类基准的**论证结构**更收敛？

**主指标**：人类侧覆盖（加权）= Σ(每个人类节点的最高边权重) / 人类节点总数。

辅指标（独立报告）：
- 人类侧覆盖（二值）：至少有一条 EQUIVALENT/蕴含边的人类节点占比
- 模型侧精度（加权/二值）：模型节点中被匹配者的平均权重
- 分层报告：A 层（结论）/ B 层（章节标题）/ C 层（段落主张）

**权重**：EQUIVALENT=1.0；H_ENTAILS_M / M_ENTAILS_H=0.5；CONTRADICTION=0；UNCERTAIN=0（单独报告，不进主指标）。

## 三、管线总览

### 阶段 0 · 数据准备（脚本目录：`脚本/步骤1_原文解析与清洗/`、`脚本/步骤8_Q_A_实验/`）

| 步骤 | 脚本 | 调用 | 目的 | 输出文件 |
|---|---|---|---|---|
| 0.1 原文清洗 | `清洗.py` / `数据清洗.py` | 无 LLM，确定性规则 | PDF→段落 JSON：切分、跨页合并、页码继承（A05/B05/C01 走块级切分开关）；`RE_HISTORICAL` 含 40+ 年号正则 | `原文_clean.json`（每段含 id/page/text） |
| 0.2 史料脚注提取 | `全量M提取.py` + `M定位_csv.py` | 无 LLM，**绝不进 ABC** | 确定性提取一手史料脚注（M 层），同篇内 C 的 sources 对齐到脚注编号 | M 层 CSV/JSON |
| 0.3 史料池派生 | `派生SML史料池.py` | 无 LLM | 构造三档上下文宽度的史料池（24 源/75 段），S/M/L 仅宽度不同 | `source_pool_{S,M,L}.json` |

### 阶段 1 · 论文生成（自变量施加点）

| 步骤 | 脚本 | 调用 | 目的 | 输出文件 |
|---|---|---|---|---|
| 1.1 条件生成 | `Q条件生成.py` / `A条件生成.py` | deepseek-chat，T=0.7，max_tokens=32768，单次调用 | **唯一自变量=前置指令**；同一史料池同一题目生成一篇论文 | `生成_论文.md` + `meta_生成.json`（模型/温度/史料池统计/usage/时间戳） |

格式约定：两组除 condition 字段与指令模板外，其余 meta 字段必须完全一致（paper_id、run_no、tier、source_pool）。当前基准：prompt 约 9.8k 字符，输出 7–9k 字符，约 13–14k tokens/篇。

### 阶段 2 · 论证树抽取

| 步骤 | 脚本 | 调用 | 目的 | 输出文件 |
|---|---|---|---|---|
| 2.1 整树抽取 | `_论证树一次性抽取.py` | deepseek-chat，**整篇一次调用** | 保留 A/B/C 论点、剔除论据（史料复述/数据罗列/引文=M 层一律 excluded）；M 由 anchor 段 `material_refs` 确定性绑定，不进 LLM | `run.json`（树 + `encoding_table`）+ `meta.json`（调用耗时）+ `_intermediate/` |
| 2.2 结构校验 | `run校验器.py` | 无 LLM | 编号连续性、层级合法性、M 绑定完整性 | 通过标准：ERRORS: NONE |

层级约定：A=结论（depth=1，全文唯一）；B=章节标题（一级 depth=2、（一）depth=3、1. depth=4）；C=段落主张（叶）。人类基准与模型侧同一管线，粒度可比。

### 阶段 3 · 人机对齐（核心测量）

| 步骤 | 脚本 | 调用 | 目的 | 输出文件 |
|---|---|---|---|---|
| 3.1 整树对齐 | `_整树LLM对齐.py --paper A05 --run X --repeats 6` | deepseek-chat，**T=0**，6 轮重复，swap/非swap 各半交替 | 两侧整棵树按 DFS 章节顺序匿名编号（人类侧 a001…，模型侧 b001…），swap 左右交换实现盲态；命令式符号输出：`a=b`（等义）、`a>b`（甲蕴含乙）、`a<b`（乙蕴含甲），仅列真实论证点对应 | `整树_LLM对齐.json`：`pairs`（r0）+ `extra_repeats`（r1–r5，各含 seed/swapped/raw_response/pairs）+ `repeat_agreement`（15 对配对一致率）+ `label_conflicts` + `aggregate`（r0 单轮聚合）+ `usage` |
| 3.2 频次聚合 | `_频次聚合.py [run_dir]` | 无 LLM，本地计算 | 统计每条 (human,model) 边在 6 轮中的出现频次与标签分布；阈值扫描；多数票标签 | `频次聚合.json`：`freq_distribution` + `label_consistent_edges` + 阈值扫描表 + `edges_k_ge_4` |

成本基准：Q 组（57 节点）约 19.8k tokens/6 轮；A 组（48 节点）约 18.4k tokens/6 轮。

## 四、判定与聚合规则

1. **单轮不可采信**。同输入 T=0 多轮的边数摆动是基础设施级随机性（GPU 浮点求和顺序、MoE 路由），调参无法消除。
2. **频次投票**：边按 6 轮中出现次数分档；**6/6 全现 = 跨排布共识核**（swap 与非 swap 两个"独立评审"都认，最可信）；k≥4 进主聚合（现行约定，文献建议未来扩到 10 轮 + k≥6/10）。
3. **标签多数票**：同一边跨轮标签漂移独立于边稳定性（Q 组仅 22% 全一致），每条边取出现频次最高的标签。
4. **swap 偏差已知且未消除**：swap 轮系统性多吐边（Q +40%、A +95%），跨排布一致率仅 ~0.02。处理方式：不把 swap 当中性盲态，而当**第二评审**，取两评审交集（即 6/6 核）为报告口径。
5. **报告口径**：主表报 6/6 核的 H 覆盖加权（主指标）+ k≥4 口径作稳健性对照；单轮聚合数字仅作"虚高参照"（实测虚高约 4.4 个百分点）。

## 五、已知误差源与质量控制

| 误差源 | 证据 | 控制 |
|---|---|---|
| T=0 逐位不确定 | Atil 2025（5 模型 10 次无一逐字一致）；Nicholson 2026（T=0 约 1/4 输出变化） | 多轮频次投票；报告轮间分布而非单轮值 |
| swap 系统偏差 | 两组实验 swap 轮边数 +40%/+95%，跨排布一致率 0.02 | 6/6 跨排布共识核为报告口径 |
| 标签方向漂移 | 6/6 边的标签也未必全一致 | 多数票标签；人工盲标校准（阶段 5） |
| 单轮虚高 | r0 聚合 H 覆盖 0.4853 → 6/6 核 0.4118 | 不报告单轮数字进正文 |
| 测量误差组间不等 | Q 组（57 节点）评委自身漂移大于 A 组（48 节点） | 报告 Q/A 差值时注明 Q 组在更噪测量下仍占优 |
| 生成侧单次采样 | T=0.7 一次运行只是一次采样 | 扩展计划：同一条件多次生成（见第七节） |
| 轮数不足 | 6 轮低于 self-consistency 与 seed 文献共同门槛（10 次） | 补到 10 轮，阈值 k≥6/10 |

## 六、当前结果快照（A05 / S 档 / run_2，各 6 轮）

| 指标 | Q 组（论从史出） | A 组（以论带史） |
|---|---|---|
| 模型节点数 | 57 | 48 |
| 每轮边数 | 71–109（散） | 37/74 双峰（同排布近完美复现） |
| swap 偏差 | +40% | +95% |
| 6/6 跨排布共识核 | 54 条 | 19 条 |
| 标签全一致率 | 22% | 80% |
| **H 覆盖加权（k≥4）** | **0.4412** | **0.3235** |
| H 覆盖二值（k≥4） | 0.8824 | 0.5294 |
| M 精度加权（k≥4） | 0.3509 | 0.2292 |

**初步结论**：Q 条件生成的论文与人类基准论证结构更收敛（H 覆盖 0.44 vs 0.32），且是在更噪的测量条件下得出的——方向支持 H1（论从史出 > 以论带史）。**边界**：仅 1 篇论文 × S 档 × run_2，未到可推广结论的样本量。

## 七、扩展计划（按优先级）

1. **人工盲标**（阶段 5）：Q 组 54 条 + A 组 19 条稳定核，校准评委准确率——这是主指标可信的前提。
2. **扩论文**：B05、C01 复制全管线（S 档先行），得 3 篇 × Q/A 的差值方向。
3. **扩档位**：A05 的 M/L 档，检验史料宽度对收敛度的影响。
4. **补轮数**：全部 run 补到 10 轮，主口径切 k≥6/10（54/19 条 6/6 核天然满足，无需重跑）。
5. **生成侧多次采样**：同一条件生成 3 篇（T=0.7），报告跨生成 run 的覆盖均值±极差，排除单次生成偶然性。
