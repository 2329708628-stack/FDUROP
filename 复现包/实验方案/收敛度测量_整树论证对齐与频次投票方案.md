## 一、动机与演进脉络

| 阶段 | 方案 | 结果 | 弃用/保留原因 |
|---|---|---|---|
| v1 细粒度 | 原子命题 + NLI | 地板效应：DIFFERENT 占 98.8%，覆盖率 0–0.09 | 拆太碎，颗粒度不对等污染分母 |
| v2 粗粒度 | 段落级主旨论点 | 诊断对照用 | 强制合并异构断言，分辨率低 |
| v3.2 | 分层抽取（5 次调用） | 可用但成本高 | 已备份为 run_v3.2_backup.json |
| **v4 当前** | **非原子化整树 LLM 对齐** | 6/6 执行稳定、22k token、10/10 配对质量 | **主方案** |
| v4.0 旁支 | NLI 客观信号合并（`客观信号.json`：cos + e/c 概率 × LLM 频次） | 尝试后发现对下游无用 | **已弃用**：改用多轮频次投票（多轮取平均/多数票）治理漂移，客观信号仅存档备查 |
| v4.1 | + 多轮频次投票 | 治理 T=0 漂移 | 本方案核心增量 |

整树方案胜出的三条理由：

1. **原子化拆分工具本身未验证**：把论点拆成原子命题的拆分管线从未经人工盲标校准，拆分质量与粒度可比性不可知，下游误差无法归因（是拆坏了还是比坏了）；
2. **上下文过长、稳定性太差**：382 条命题全量对齐超出模型执行边界（格式崩溃、编号漂移、输出长度失控）；拆碎+顺序打乱消灭上下文连贯与位置局部性，模型无法利用叙事流和相邻段落先验，判定漂移；
3. **结构化拆分有预实验背书**：按论证结构（A/B/C 整树）组织的方案经预实验对照全面胜出——执行稳定（6/6 成功 vs 原子化频繁崩溃）、Token 成本（22k vs 40–55k）、配对质量（10/10 真实论证点对应 vs 原子化约 30% 话题误判）、同输入复现性（完全一致 vs 差）。整树保持章节顺序后，同输入复现性显著改善。

新暴露的问题及对策：T=0 不保证逐位确定性（Atil 2025、Nicholson 2026），输出边数在轮间摆动 → 用**多轮频次投票**治理，不追求单轮复现。

## 二、实验设计与指标体系

### 2.1 析因设计（2×3 完全因子，沿用主方案）

| 自变量 | 水平 | 施加点 |
|---|---|---|
| ① 前置指令（问题意识） | Q（论从史出）/ A（以论带史） | 生成提示词模板 |
| ② 史料上下文规模 | S（原句级）/ M（段落级）/ L（篇章级） | `source_pool_{S,M,L}.json`，三档仅宽度不同 |

6 个交叉单元格（Q-S、Q-M、Q-L、A-S、A-M、A-L）全覆盖；每格 N=5–10 次独立生成运行（当前完成：1 篇论文 × S 档 × Q/A 两格）。控制变量：同一史料池（M_human 全量）、同一模型/温度/题目。有效性约束：漏用任一 M 的生成 run 判无效。

### 2.2 指标体系（名称沿用主方案，比较口径统一为覆盖型）

**ACI（命题收敛度）** = 归一化后与人类基准重合的命题数 ÷ 人类命题总数。分层报告 A/B/C；模型侧精度（被匹配的模型命题占模型命题总数之比）独立报告，用于捕捉注水。取值 [0,1]，越高越收敛。
不采用 Jaccard 距离口径：其分母随模型输出量浮动，与篇幅耦合且存在触顶饱和（一期实测 Q-S/Q-M 饱和为 1.000 失去区分度）。

**SCI（边收敛度）** = 归一化后与人类基准重合的结构边数 ÷ 人类结构边总数。结构边 = 祖先节点到 M 的边（C→M、B→M，排除 A→M 与 M→A），节点经语义归一化映射为统一类别 ID、保留方向、剔除单轮内重复边。取值 [0,1]，越高越收敛。

**辅助描述性指标**：M 覆盖率（模型使用的史料单元数 / 史料池总单元数）；M 选中频率分布；引用偏移（模型引用语句与史料核心句的字符距离）。

**有效性约束**（主方案）：漏用任一 M 的生成 run 判无效，剔除并补跑。

**统计口径**（主方案）：以「ACI 组间差值、SCI 组间差值」为核心效应量，**以完整论文为统计单位**，禁止合并多篇论文的 C 节点计算整体指标；组间差异用符号检验与置换检验，置信区间用 jackknife 删一法。

## 四、判定与聚合规则

1. **单轮不可采信**。同输入 T=0 多轮的边数摆动是基础设施级随机性（GPU 浮点求和顺序、MoE 路由），调参无法消除。
2. **频次投票**：边按 6 轮中出现次数分档；**6/6 全现 = 跨排布共识核**（swap 与非 swap 两个"独立评审"都认，最可信）；k≥4 进主聚合（现行约定，文献建议未来扩到 10 轮 + k≥6/10）。
3. **标签多数票**：同一边跨轮标签漂移独立于边稳定性（Q 组仅 22% 全一致），每条边取出现频次最高的标签。
4. **swap 偏差已知且未消除**：swap 轮系统性多吐边（Q +40%、A +95%），跨排布一致率仅 ~0.02。处理方式：不把 swap 当中性盲态，而当**第二评审**，取两评审交集（即 6/6 核）为报告口径。
5. **报告口径**：主表报 6/6 核的 H 覆盖加权（主指标）+ k≥4 口径作稳健性对照；单轮聚合数字仅作"虚高参照"（实测虚高约 4.4 个百分点）。

## 五、已知误差源与质量控制

| 误差源 | 证据 | 控制 |
|---|---|---|
| T=0 逐位不确定 | Atil 2025（5 模型 10 次无一逐字一致）；Nicholson 2026（T=0 约 1/4 输出变化） | 多轮频次投票；报告轮间分布而非单轮值 |
| swap 系统偏差 | 两组实验 swap 轮边数 +40%/+95%，跨排布一致率 0.02 | 6/6 跨排布共识核为报告口径 |
| 标签方向漂移 | 6/6 边的标签也未必全一致 | 多数票标签；人工盲标校准（阶段 5） |
| 单轮虚高 | r0 聚合 H 覆盖 0.4853 → 6/6 核 0.4118 | 不报告单轮数字进正文 |
| 测量误差组间不等 | Q 组（57 节点）评委自身漂移大于 A 组（48 节点） | 报告 Q/A 差值时注明 Q 组在更噪测量下仍占优 |
| 生成侧单次采样 | T=0.7 一次运行只是一次采样 | 扩展计划：同一条件多次生成（见第七节） |
| 轮数不足 | 6 轮低于 self-consistency 与 seed 文献共同门槛（10 次） | 补到 10 轮，阈值 k≥6/10 |

## 六、当前结果快照（A05 / S 档 / run_2，各 6 轮）

| 指标 | Q 组（论从史出） | A 组（以论带史） |
|---|---|---|
| 模型节点数 | 57 | 48 |
| 每轮边数 | 71–109（散） | 37/74 双峰（同排布近完美复现） |
| swap 偏差 | +40% | +95% |
| 6/6 跨排布共识核 | 54 条 | 19 条 |
| 标签全一致率 | 22% | 80% |
| **ACI（覆盖型，k≥4 口径）** | **0.4412** | **0.3235** |
| ACI 二值口径（k≥4） | 0.8824 | 0.5294 |
| 模型侧精度（独立报告，k≥4） | 0.3509 | 0.2292 |
| M 覆盖率（辅助指标） | 51/73 = 69.9% | 66/73 = 90.4%（人类基准自身 35/73 = 47.9%） |
| **SCI（覆盖型，k≥4）** | **0.1143**（8/70） | **0.0714**（5/70） |
| **SCI：M 收敛**（归一化后共同指向同一 M） | —：15/15 共同对齐节点全部收敛（剔除全池污染后 13/13） | 同左 |
| **SCI：B 收敛**（共同指向同一章节） | —：宽口径 6/15、严口径 2/15 | 同左 |

**初步结论**：
1. Q 条件生成的论文与人类基准论证结构更收敛（ACI 0.44 vs 0.32），且是在更噪的测量条件下得出的——方向支持 H1（论从史出 > 以论带史）。
2. **收敛度分层**：论点内容部分收敛（Q>A），证据维度完全收敛（凡共同对齐的论点，Q/A 引用史料必然同源，无一例指向完全不同史料），章节位置发散（40% 宽收敛）——前置指令（自变量①）作用在**组织编排**层，不在证据选用层。
3. **边界**：仅 1 篇论文 × S 档 × run_2（2×3 设计的 1/6），未到可推广结论的样本量。
4. **数据质量待修**：A1、C1.1、C5.1 三个节点 sources 为全池绑定（anchor 为引言/结论大段时 material_refs 全部并入），需在校验器加阈值告警。

## 七、扩展计划（按优先级）

1. **人工盲标**（阶段 5）：Q 组 54 条 + A 组 19 条稳定核，校准评委准确率——这是主指标可信的前提。
2. **扩论文**：B05、C01 复制全管线（S 档先行），得 3 篇 × Q/A 的差值方向。
3. **补全 2×3 析因**：A05 的 M/L 档 × Q/A 四个单元格（自变量②史料上下文规模），得完整 6 格条件空间；检验上下文宽度对 ACI/SCI 的影响（主方案预期：上下文规模与收敛度的交互）。
4. **补轮数**：全部 run 补到 10 轮，主口径切 k≥6/10（54/19 条 6/6 核天然满足，无需重跑）。
5. **生成侧多次采样**：同一条件生成 3 篇（T=0.7），报告跨生成 run 的覆盖均值±极差，排除单次生成偶然性（对应主方案 N=5–10）。
6. **修全池绑定**：`run校验器.py` 加单节点 sources 数阈值告警（建议 ≤15），A1/C1.1/C5.1 类全池绑定节点在 SCI 计算中剔除或降权。
