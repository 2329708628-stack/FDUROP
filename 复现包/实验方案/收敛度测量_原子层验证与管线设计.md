# 收敛度测量：原子层验证与管线设计

> 日期：2026-09-21
> 前置文档：《收敛度测量_失败日志.md》《收敛度测量_诊断记录.md》《收敛度测量_预实验报告.md》
> 本轮目的：在"测量单位=原子命题"的前提下，验证三个仪器（LLM 六类判定 / 余弦 / NLI）各自的表现，据此定管线。

---

## 一、为什么改测量单位

预实验（见报告）暴露的根因：**C 层"段落大意"作为比对单位不可用**——概括句主题饱和（余弦退化）、复合断言扫射（一条扫中 15 条）、粒度随分段漂移。原子化（组员实施包的"保真原子化"规范）把测量单位从"段落大意"换为"可独立判断的原子命题"，本轮验证它是否解决上述病症。

---

## 二、实验一：原子化 + LLM 六类判定（原型）

**方法**：对 A05/Q_run_1_S 的两个扫射案例（`M[C3.2.2.1]` 旧扫 15 条、`M[C3.2.1.1]` 旧扫 12 条），用组员 prompt 做保真原子化（双侧同管线），再对 758 对原子对做六类判定（EQUIVALENT / A_ENTAILS_B / B_ENTAILS_A / CONTRADICTION / DIFFERENT / UNCERTAIN）。

**结果 1：扫射被消解**

| 案例 | 旧命中 | 原子级仍成立 |
|---|---|---|
| M[C3.2.2.1]（租赁服务） | 15 条（1 等义 + 14 部分重叠） | **3 条** |
| M[C3.2.1.1]（市场规模） | 12 条 | **5 条** |
| 合计（19 条人类主张） | 27 条命中 | **8 条**（1 EQUIVALENT + 7 单向蕴含） |

翻掉的 11 条全部给出可核查理由（"主题相关但命题内容不同，互不蕴含"）。

**结果 2：单向蕴含成为新的承载档**

存活 8 条中 7 条是单向蕴含（模型比人类更具体 / 人类比模型更具体），仅 1 条 EQUIVALENT。旧"部分重叠"大口袋缩小为一个**明确可校准的问题**：单向蕴含算不算命中。此档自身也有松动（如 "市场规模巨大 ⊨ 市场繁荣" 牵强），需人工裁定。

**结果 3：对 Q_run_1_S 覆盖率的冲击**

- 3 条确定掉出覆盖（C1.4、C2.3、C5.2——仅扫射单一来源）；8 条仅剩"其他未重判主张"的边；
- 宽松口径（等义+单向蕴含算命中）：**0.80 → 区间 0.43–0.70**（上界假设未重判边全有效，偏乐观）；
- 严格口径（仅等义）：19 条仅剩 1 条，将远低于 0.43；
- 模型侧 precision：12/17 → 11~12/17。

**成本**：758 对判定 + 21 次原子化 = **393,682 token**（prompt 294,580 + completion 99,102），约 20 分钟；原子化粒度约 5 原子/条。

**判定**：原子化方向成立；LLM 六类判定可用且理由可核查。遗留问题：单向蕴含档的口径需人工校准；全量铺开必须做召回剪枝。

## 三、实验二：原子层余弦复测（本地，零 API）

**方法**：对同一批 758 对原子对计算句向量余弦，与六类标签对照。

**结果**：

| 组 | n | 余弦（均值 / 中位） |
|---|---|---|
| EQUIVALENT（真等义） | 1 | 0.831 / 0.831 |
| A_ENTAILS_B | 9 | 0.313 / 0.367 |
| DIFFERENT | 747 | 0.694 / **0.779** |

- **AUC = 0.214 —— 排序倒挂**：真等义对（0.831）低于无关对的中位数；
- τ=0.60 对无关对通过率 **71.1%**（旧 gist 层 79.4%，几乎无改善）；
- 最刺眼：`"杀猪羊作坊上市动辄百数" ↔ "这些动物交易市场折射出市民文化多元"` = **0.992**；`"鹌鹑价格低至二文" ↔ "牙人将诉诸法律的纠纷消弭于萌芽"` = 0.982。

**判定**：**余弦在原子层失效**——它编码的是主题/文体相似度，原子越短、"共同主题词"权重越大；真对（实体共享但句式不同）反而分低。不能作判定器；作召回器也有系统性漏真对的风险（排序倒挂 → top-k 被主题级近邻占满）。

## 四、实验三：原子层 NLI 复测（本地，零 API）

**方法**：mDeBERTa-v3 XNLI 模型，双向蕴含（A→B、B→A），与六类标签对照。

**结果**：

- **方向判定：9/9 全对**（且干脆：`"京师人多赁马赁驴出入" ⊨ "大量牲畜被用作租赁"` = 0.97 / 0.04）；
- 排序能力 **AUC = 0.861**（max 方向蕴含）；
- **但 θ=0.50 时 161 条无关对误通过**（747 条 DIFFERENT 中 21.6%），精度不足；误报几乎全是**抽象评价词**类原子：`"屠宰业客观上推动动物交易市场扩大" ⊨ "存栏量之大"` = 0.99、`"酒店业繁荣推动了动物市场繁盛" ⊨ "市场规模巨大"` = 0.99（NLI 的词汇重叠偏差）；
- 漏检存在：真蕴含 `"租赁鞍马不过百钱" ⊨ "民用坐骑较便宜"` 仅 0.06；
- 有一例 NLI 可能比 LLM 更对：`"生鱼数千檐入门" ↔ "活鱼交易数额巨大"`（LLM 判 DIFFERENT，NLI 给 0.99）——提示 LLM 参照本身有噪声，需人工裁决。

**判定**：NLI 复活但**不能单独终审**；定位为**方向指示器 + 候选排序器**。若单独承担召回需把阈值压到极低（0.05 才能召全 9 条真对），失去剪枝意义——所以召回的可行性要靠下面的两级架构解决。

## 五、从三组结果得到的约束

| 编号 | 约束 | 依据 |
|---|---|---|
| C1 | 终审必须由 LLM 承担 | 余弦 AUC 0.21；NLI 抽象词误报多、precision 不足 |
| C2 | 召回不能靠原子层余弦（倒挂） | 实验二 |
| C3 | 召回层应放在"主题层"（段落/主张），原子层只在召回对的**内部**做全组合 | 余弦擅长主题相似；11 条已知真原子对全部落在旧 gist 匹配对内部 |
| C4 | 判定口径双报：宽松（等义+单向蕴含）/严格（仅等义） | 单向蕴含承载了 7/8 存活命中；口径冻结需人工盲标 |
| C5 | 分母锚在段落（P）：指标用"段落内覆盖比例" | 段落集合是确定性的（非 LLM 产物）；应对原子数波动 |
| C6 | 结构与测量解耦 | Q/A 生成结构不同（同篇 3 章 vs 5–6 章），按章节阻断会系统性漏检 |
| C7 | 召回必须双向并集 + 多路，不接受单方向/单路 | 实测：模型→人类方向 top-5 只召回 1/8；双向并集 8/8（2 条卡边界） |
| C8 | A 不进指标（A 组被喂 A_H，比它循环）；B/C 计入；层级报告靠叶层向上聚合 | A 的用途=操纵基准 + 结构呈现 + 操纵检查 |
| C9 | 结语段统一不进测量（正文论证段才计入） | 当前数据不一致：B05 基线含结语主张（50→48）、C01 模型侧含（21→18）、A05 不含 |

## 六、拟定管线（当前思路的形式化）

```
Step 0  宏观逻辑树（层级结构，不是固定三层）
        树 = A（顶层结论）→ 各级小标题（B 层，可多级）→ 段落 P（叶）；
        B 层由正则（标题层级）机械得出；
        A 由 LLM 概括 + 人工确认冻结（允许复杂句；记录来源段与 synthesized 标记）；
        "C" 为虚指：A 之下各层级的统称，测量单位落在叶层（段落论点，1± 条）。
        测量发生在叶层；A 不进指标（A 条件的注入目标，比它循环），B/C 可进；
        各级报告由叶层结果沿树向上聚合得到。

Step 1  段落 → 原子（保真原子化）
        per-段落调用（组员 prompt），temperature=0，span 锚定 + 冻结版本化；
        抽样人工核验（她协议：20–30 个母节点）；输出原子继承结构路径 A1-B2-B2.1-P12。

Step 2  召回（多路并集，目标：滤掉完全不相关的，压缩 LLM 计算量）
        L1（主张层，双向并集，k=8 起步）：
          路1 余弦 top-k（主题层，已验证可行）
          路2 词汇-实体重叠 top-k（补"共享专名/数字、但主题词不相似"的对）
          路3 NLI max(ent) top-k′（只用排序不用阈值；AUC 0.861 为各仪器最高）
        L2：召回对内部做原子×原子组合（原子数上限约束成本）；
        召回率由"未命中复核"实测（目标：漏检 ≤10%，Q/A 之差 ≤3pp）

Step 3  LLM 六类判定（终审）
        对候选原子对判 EQUIVALENT / A_ENTAILS_B / B_ENTAILS_A /
        CONTRADICTION / DIFFERENT / UNCERTAIN；匿名化（不传条件与来源）。

Step 4  聚合（双口径 + 结构切片）
        主指标：段落内覆盖比例（分母=段落数）→ 全篇均值；
        结构指标：章节对齐矩阵、结构对齐率（分母=内容匹配对）、分章覆盖分布；
        双口径：宽松/严格各报一遍。

Step 5  统计（面向"效应是否显著"）
        分层结构 run > 章节 > 段落 > 原子；配对置换检验（Q vs A 同篇同档）；
        报告效应量 + 区间（jackknife/置换，可复用组员 aci_reference.py）；
        每格 ≥3 轮生成后再做检验。
```

**召回实测（Q_run_1_S，8 对已知真对的父主张对，2026-09-21）**：

| 召回方向 | top-5 命中 |
|---|---|
| 人类→模型 | 8/8（排名 1–5，其中 2 条卡在第 5 名，零余量） |
| 模型→人类 | **1/8**（其余真对排名 8–29） |
| 双向并集 | 8/8 |

结论：① 必须**双向并集**，单方向会塌；② k=5 太紧 → 起步 **k=8**，取值由召回率验证调；③ 余弦只承担一路，另加词汇-实体、NLI 排序两路；④ 上表存在幸存者偏差（只覆盖已发现的真对），**未召回的未知真对**只能靠"未命中复核"实验估计。

**待定项（需实验或校准定，不先验拍板）**：

1. 召回参数：余弦 k（8 起步）、NLI k′——由召回率验证实验定；
2. 原子数是否需要设上限（控成本）；
3. 口径冻结：单向蕴含算不算命中——由分层人工盲标（含 Q/A 各自一致率）定；
4. 原子化源：P（原文段落）vs C（段落主张）——待做三拆稳定性对照（见下）；
5. N 轮数：显著性检验的最低重复数；
6. B 层纳入方式：叶层匹配向上聚合（推荐，避免复合主张回归扫射）vs B 层独立匹配（仅当明确需要"章节级论点对齐"时启用，须强制 EQUIVALENT + 人工核验）。

**待验证实验**：

- **召回率验证**：抽样做全配对终审，反推 L1/L2 的漏检率，**分 Q/A 条件报告**（目标：漏检 ≤10%，两条件之差 ≤3pp）；
- **原子化稳定性对照**：同 10 段文本，从 P 拆 vs 从 C 拆各 3 次（temp=0），量计数变异、实体保留率、span 保真——用数据决定原子化源；
- **条件无关性盲标**：从判定结果分层抽 150–200 对人工盲标，比较 Q/A 两组一致率（κ），作为对比可信度的直接证据。

## 七、可行性评估（对应"这样似乎比较可行"）

**成立的部分**：结构→原子→召回→LLM 终审的主链路与三组实验结果一致；两级召回解决了"原子层余弦不可用"与"全量 LLM 太贵"的矛盾；结构解耦保住了 Q/A 结构不同构下的可比性。

**两个必须守住的前提**：

1. 召回的漏检必须**条件无关**（否则效应方向被扭曲）——靠召回率验证实验兜底；
2. 判定的误差必须**条件无关**——靠分层盲标（κ_Q ≈ κ_A）兜底。

这两条过了，即便绝对数值有偏，Q/A 的效应检验依然成立——这正是当前的目标定位（只在意自变量对因变量的影响是否显著）。

**成本量级（估计）**：原子化 ~1 call/段；召回本地免费；LLM 判定为最大项（原型 ~520 token/对），靠 L1+L2 剪枝可压到每 run 数千对量级；统计与结构分析免费。
