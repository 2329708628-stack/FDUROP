# 历史学论证可复现性实验：复现包

用 LLM 生成史论论文（Q/A 两种前置指令条件），与人类基准论文的论证树做逐对对齐，测量「论证结构收敛度」。本包收录**全管线脚本**与**实验方案文档**。

主方案：《实验方案/收敛度测量_整树论证对齐与频次投票方案.md》（v4，整树对齐 + 频次投票）。

## 管线流程与运行顺序

### 阶段 0 · 数据准备（`脚本/步骤1_原文解析与清洗/`）

| 顺序 | 脚本 | 作用 | 产物 |
|---|---|---|---|
| 0.1 | `清洗.py` / `数据清洗.py` | PDF→段落 JSON：切分、跨页合并、页码继承（A05/B05/C01 走块级切分开关）；`RE_HISTORICAL` 含 40+ 年号正则 | `原文_clean.json` |
| 0.2 | `全量M提取.py` + `M定位_csv.py` | 确定性提取一手史料脚注（M 层），**不经过 LLM** | M 层 CSV/JSON |
| 0.3 | `生成史料池.py` | 构造史料池（后续派生 S/M/L 三档） | `source_pool.json` |

### 阶段 1 · 论文生成（`脚本/步骤8_Q_A_实验/`，自变量施加点）

| 顺序 | 脚本 | 调用 | 产物 |
|---|---|---|---|
| 1.1 | `Q条件生成.py` / `A条件生成.py`（共用 `提示词模板.py`） | deepseek-chat，T=0.7 | `生成_论文.md` + `meta_生成.json` |

唯一自变量 = 前置指令：Q=「基于以下史料，分析 X 与 Y 的关系」（论从史出）；A=「论证以下观点，使用给定史料支撑」（以论带史）。`派生SML史料池.py` 生成三档史料宽度。

### 阶段 2 · 论证树抽取

| 顺序 | 脚本 | 调用 | 产物 |
|---|---|---|---|
| 2.1 | `_论证树一次性抽取.py` | deepseek-chat，整篇一次调用 | `run.json`（A/B/C 论证树 + encoding_table） |
| 2.2 | `run校验器.py`（`脚本/步骤3_v3.2抽取/`） | 无 LLM | 结构校验，通过标准 ERRORS: NONE |

层级：A=结论（全文唯一）；B=章节标题；C=段落主张（叶）。M 由 anchor 段 `material_refs` 确定性绑定。人类基准用 `手工ABC_人类基准.py` 构建，与模型侧同管线。

### 阶段 3 · 人机对齐（核心测量）

| 顺序 | 脚本 | 调用 | 产物 |
|---|---|---|---|
| 3.1 | `_整树LLM对齐.py --paper A05 --run X --repeats 6` | deepseek-chat，T=0，6 轮，swap/非swap 各半 | `整树_LLM对齐.json`（pairs + 一致率 + 冲突 + usage） |
| 3.2 | `_频次聚合.py [run_dir]` | 无 LLM | `频次聚合.json`（频次分布 + 阈值扫描 + k≥4 边表） |

两侧整树按 DFS 章节顺序匿名编号（a001…/b001…），命令式符号输出 `a=b` / `a>b` / `a<b`。报告口径：**6/6 跨排布共识核为主，k≥4 作稳健性对照**；单轮聚合仅作虚高参照（实测约 +4.4pp）。

## 方法与结果要点

- T=0 不保证 LLM 输出逐位确定（文献：Atil 2025；Nicholson 2026）→ 多轮频次投票治理，推荐 10 轮 + k≥6/10（详见 `实验方案/LLM多次采样次数方法学参考.docx`）
- swap 非中性：交换左右树位置后模型系统性多输出 40–95% 边 → 把 swap 当第二评审，报告跨排布共识（6/6 核）
- A05/S/run2 初步结果：Q 组 H 覆盖加权 0.4412 > A 组 0.3235（k≥4 口径），方向支持「论从史出」更收敛；边界：仅 1 篇 × S 档 × run_2
